# 标签分类中英文对照

英文名沿用训练 `classes.txt` / 标注配置 `Label value`；中文沿用客户界面与推理对照表。判定以白皮书能力目标为默认口径，现场可按工程方案调整。带「非缺陷」的类：标注可画框、训练保留，推理默认屏蔽，不计入板级 NG。

三路线扫：**上** `cam1`、**中** `cam2`、**下** `cam3`。本表覆盖 `classes.txt` 全部 19 类。「相机」写业务主责，若与本套标注不一致会注明。

## 溢胶/胶缝类

### 崩缺 `GlueGap`

| 项 | 说明 |
|:---|:---|
| 角色 | 核心缺陷 |
| 相机 | 中（侧面主责）；本套标注在上、下。 |
| 业务定义 | 封边处崩缺：封边带或基材边角崩裂、缺料。 |
| 本质 | 材料破损缺口，不是贴合缝，也不是工艺钻孔。 |
| 判定 | 宽 >1 mm 且 长 >1 mm。 |
| 易混 | 不是 `Hole`（钻孔）。英文名 GlueGap 易被理解成胶缝间隙，中文以「崩缺」为准。 |

### 胶缝 `GlueSeam`

| 项 | 说明 |
|:---|:---|
| 角色 | 核心缺陷 |
| 相机 | 上、下（上棱/下棱主责）；侧面可见段中相机也可检。 |
| 业务定义 | 板件正反面封边带与饰面板贴合不紧密，贴合线上存在缝。 |
| 本质 | 有胶，但合缝不严；细长线状小目标（约 0.2 mm 宽）。 |
| 判定 | 宽 >0.2 mm 且 长 >5 mm。 |
| 易混 | 与开胶不同：胶缝是贴合缝没合严，开胶是没粘上。 |

### 残胶 `GlueResidue`

| 项 | 说明 |
|:---|:---|
| 角色 | 核心缺陷 |
| 相机 | 上、下（板面/棱上残胶）。 |
| 业务定义 | 封边残胶：多余胶水留在封边带或板面/棱上。 |
| 本质 | 溢胶残留，胶还在表面上，不是缝、也不是开胶。 |
| 判定 | 宽 >1 mm 且 长 >3 mm。 |
| 易混 | 易与夹胶、刮板、残带混淆。 |

### 夹胶 `ClampGlue`

| 项 | 说明 |
|:---|:---|
| 角色 | 核心缺陷（方案可默认关闭） |
| 相机 | 上、下。 |
| 业务定义 | 夹具/压辊挤出的胶团，附着在封边区域。 |
| 本质 | 来源是夹具挤压，外观接近残胶。 |
| 判定 | 按残胶同类处理（宽 >1 mm 且 长 >3 mm）；客户精度页未开时可不报出。 |
| 易混 | 与残胶同组、易混；白皮书未单列此类。 |

## 残留/无胶类

### 开胶 `Tackless`

| 项 | 说明 |
|:---|:---|
| 角色 | 核心缺陷 |
| 相机 | 中（侧面主责，分离更易见）；本套标注在上、下。 |
| 业务定义 | 板件前端/尾部封边带未涂胶，基材外露，封边带与板材分离。 |
| 本质 | 无粘性、脱粘（英文 Tackless）；带和板分开了。 |
| 判定 | 宽 >1 mm 且 长 >5 mm；也可配置为检出即 NG。 |
| 易混 | 与胶缝不同：开胶是没粘住，胶缝是合缝不严。可与胶缝同时出现。 |

### 残带-非缺陷 `ResidualTape`

| 项 | 说明 |
|:---|:---|
| 角色 | 屏蔽非缺陷 |
| 相机 | 上、下（板上或镜头光路中均可能）。 |
| 业务定义 | 加工残留的封边带碎片、残渣（板上或光路中）。 |
| 本质 | 干扰物，不是封边带损伤。 |
| 判定 | 不计入 NG / 贴标 / 排出。 |
| 易混 | 不是 `BandBroken`（封边带损伤）。框数多，去掉训练会与残胶、开胶混淆，故训练保留、推理屏蔽。 |

## 侧面高低

### 封边过低 `Below`

| 项 | 说明 |
|:---|:---|
| 角色 | 核心缺陷 |
| 相机 | 中。 |
| 业务定义 | 封边带低于上/下表面饰面板，刮伤基材、露底。 |
| 本质 | 侧面贴合高度不够，封边带沉下去。 |
| 判定 | 高 >0.3 mm 且 长 >5 mm（现场可改为软件书 H<0.1 mm 等口径）。 |
| 易混 | 不是崩缺；露底来自高度差，不是边角崩裂。 |

### 封边过高 `Above`

| 项 | 说明 |
|:---|:---|
| 角色 | 其它（方案默认关闭，默认不训练） |
| 相机 | 中。 |
| 业务定义 | 封边带高于上/下表面饰面板，刮手、高出板件。 |
| 本质 | 整条封边带侧面偏高，不是局部鼓包。 |
| 判定 | 软件书高 >0.2 mm；现场方案默认不启用。 |
| 易混 | 局部鼓起是 `Bumps`（鼓包），不是本类。样本极少。 |

## 长条类

### 短带 `Shorter`

| 项 | 说明 |
|:---|:---|
| 角色 | 核心缺陷 |
| 相机 | 中（本套样本均在中相机）；端头上/下缘可见时上或下也可检。 |
| 业务定义 | 板件前端/尾部封边带未完全覆盖基材，造成露底。 |
| 本质 | 封边带长度不足，没包到头。 |
| 判定 | 长 >1 mm（按长度判）。 |
| 易混 | 与过长相反：短带是没盖住，过长是超出未齐平。 |

### 过长 `Longer`

| 项 | 说明 |
|:---|:---|
| 角色 | 核心缺陷 |
| 相机 | 上或下（端头上缘/下缘可见时，本路独立判）。 |
| 业务定义 | 进料口/出料口封边带明显突出板材，端头未齐平。 |
| 本质 | 封边带超出板端，长度超差。 |
| 判定 | 长 >1 mm（按长度判）。 |

### 过长2 `Longer2`

| 项 | 说明 |
|:---|:---|
| 角色 | 核心缺陷 |
| 相机 | 上或下（同过长）。 |
| 业务定义 | 同「过长」：端头封边带突出、未齐平。 |
| 本质 | 过长的另一外观形态（同业务、不同视觉样子），样本较少。 |
| 判定 | 按过长处理（长 >1 mm）；现场方案可单独设阈值。 |

## 封边带损伤

### 封边带损伤 `BandBroken`

| 项 | 说明 |
|:---|:---|
| 角色 | 核心缺陷（**确定缺陷**） |
| 相机 | 中。 |
| 业务定义 | 封边带破损、撕裂或缺口；已能确认是损伤。 |
| 本质 | 封边带本体受伤，不是加工残渣。 |
| 标注形态 | **确定缺陷**：通常能看到破损面（断面/撕裂面暴露，可见白茬、纤维或断面纹理）。 |
| 判定 | 宽 >1 mm 且 长 >1 mm。 |
| 易混 | 不是 `ResidualTape`（残带）；与 `BandBroken2` 用「确定 vs 疑似」区分。 |

### 封边带损伤2 `BandBroken2`

| 项 | 说明 |
|:---|:---|
| 角色 | 其它（**疑似缺陷**，近义 `BandBroken`，不单列验收） |
| 相机 | 中（同封边带损伤）。 |
| 业务定义 | 疑似封边带损伤，尚不能确认；无独立客户中文名。 |
| 本质 | 与 `BandBroken` 同业务族，置信度不足，样本较少。 |
| 标注形态 | **疑似缺陷**：通常看不到清晰破损面（多从背面/未露断面视角，只能看到轮廓或疑似外形）。 |
| 判定 | 不按核心缺陷单列验收；不写入 `/v1/labels`。训练可保留。 |
| 易混 | 角部「缺一块料」优先 `GlueGap`（崩缺），不要标成 `BandBroken2`；能确认破损面时用 `BandBroken`，不能确认时用 `BandBroken2`。 |

## 凹凸、孔洞、划伤

### 鼓包 `Bumps`

| 项 | 说明 |
|:---|:---|
| 角色 | 核心缺陷 |
| 相机 | 上、下；侧面鼓起时中相机也可能看到。 |
| 业务定义 | 封边带局部鼓起、凸包。 |
| 本质 | 局部凸起，不是整条封边带整体偏高。 |
| 判定 | 按表面凹凸/压痕口径：宽 >0.4 mm 且 长 >5 mm；现场也可按长度单独判。 |
| 易混 | 不是 `Above`（封边过高，方案默认关闭）。 |

### 钻孔-非缺陷 `Hole`

| 项 | 说明 |
|:---|:---|
| 角色 | 屏蔽非缺陷 |
| 相机 | 上（本套样本均在上相机）。 |
| 业务定义 | 板件上的工艺钻孔。 |
| 本质 | 正常工艺孔，不是崩缺。 |
| 判定 | 不计入 NG / 贴标 / 排出。 |
| 易混 | 崩缺是 `GlueGap`，不是 `Hole`。 |

### 刮板 `Scrape`

| 项 | 说明 |
|:---|:---|
| 角色 | 核心缺陷 |
| 相机 | 上、下（上/下表面）。 |
| 业务定义 | 刮刀/刮板工序在封边带表面留下的刮痕、压痕。 |
| 本质 | 表面伤，对应白皮书「封边带表面划伤/压痕/凹凸不平」。 |
| 判定 | 宽 >0.4 mm 且 长 >5 mm。 |
| 易混 | 易被判成胶缝；表面伤以本类为准。 |

### 划伤 `Scratch`

| 项 | 说明 |
|:---|:---|
| 角色 | 其它（样本极少，不作为核心验收项） |
| 相机 | 中（本套样本在中相机）。 |
| 业务定义 | 封边带表面划伤。 |
| 本质 | 与刮板同类的表面伤。 |
| 判定 | 按划伤/压痕：宽 >0.4 mm 且 长 >5 mm。 |
| 易混 | 表面伤以 `Scrape`（刮板）为准；本类仅保留对照。 |

### 锯齿-非缺陷 `Zigzag`

| 项 | 说明 |
|:---|:---|
| 角色 | 屏蔽非缺陷 |
| 相机 | 上、下。 |
| 业务定义 | 裁切形成的锯齿边。 |
| 本质 | 工艺边缘形态，不是须报出的波浪纹。 |
| 判定 | 不计入 NG / 贴标 / 排出。 |
| 易混 | 波浪纹业务类是 `BandWave`（不在本 `classes.txt`，当前无训练样本），不是 `Zigzag`。 |
