# 生产需求分析
60m/min ≈ 1000mm/s， 若单像素精度0.029mm，则每秒需处理 34,483 像素行。
线扫相机通常以“条带”方式触发，假设每次采集1024行，则每秒需处理 ~34帧 1024×N 图像

检测0.2mm宽、5mm长的胶缝，对应图像中仅 7×172 像素 的极小目标。
当前分辨率1024*1024需要切片检测，或者提升分辨率2048*2048可能才能满足。

MV-CL024-91GM相机 2448 × 2048， 如果视野900mm，精度是900÷2448 ≈ 0.367mm
