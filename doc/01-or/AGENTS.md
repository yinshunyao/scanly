# 原始需求目录（01-or）

## 目录用途

存放 scanly（板材封边缺陷智能检测）的原始需求文档，作为业务与能力要求的唯一真源。

## 文档范围

**允许放入：**

- 按主题拆分的独立 OR 文档（背景 / 目标 / 要求 / 工作项）

**不应放入：**

- 架构与接口设计细节（放 `doc/02-dr/`）
- 测试用例设计（放 `doc/03-tr/`）
- 客户原文资料（放 `doc/00-客户资料/`，只读引用）

## 编辑规则

- 文档命名：`【主题分类】具体需求描述.md`
- 强制五章：`# 背景` / `# 目标` / `# 要求` / `# 当前工作项` / `# 已完成工作项`
- 一需求一文档；有效需求内容（不含已完成工作项）建议不超过 150 行
- 任务完成后将「当前工作项」迁入「已完成工作项」

## 协作约定

| 相邻目录 | 关系 |
|:---|:---|
| `doc/00-客户资料/` | 需求输入来源；不修改客户原文 |
| `doc/02-dr/` | 由本目录 OR 驱动设计 |
| `doc/03-tr/` | 与设计同步产出测试设计 |

优先级：本目录要求 > 设计默认值 > 实现便利性。
