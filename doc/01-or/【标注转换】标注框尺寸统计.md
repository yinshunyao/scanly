# 背景

封边缺陷检测样本经 Label Studio 转换后得到 YOLO11 / LabelImg（VOC）标注。训练前需要按类别统计框数量、归一化与像素尺寸（对角线或最长边）、分箱分布及极值文件，便于发现异常框与设定训练超参。insect 侧已有 `stat_annotation_from_xml.py`，scanly 需在本工程工具目录提供同类能力，并贴合 YOLO txt / VOC xml 与 `Categories.json`。

# 目标

1. 对 scanly 缺陷标注目录统计各类别框数量与尺寸指标。
2. 支持 YOLO11 `.txt` 与 LabelImg Pascal VOC `.xml` 两种输入。
3. 输出控制台汇总，并写入可归档的文本统计文件。

# 要求

## 功能性要求

1. **输入格式开关**：`yolo`（`class cx cy w h` 归一化 txt）或 `voc`（Pascal VOC xml）。
2. **类别名**：优先 `Categories.json` / YOLO `data.yaml` 的 `names`；VOC 可从 xml 的 `object/name` 建立映射。
3. **尺寸指标**：默认对角线 `sqrt(w^2+h^2)`，可切换为最长边 `max(w,h)`；同时给出归一化与像素统计、面积统计。
4. **分箱**：对各类别像素尺寸指标按固定边界输出区间计数与占比。
5. **极值定位**：记录每类尺寸指标 min/max 及对应标注文件名。
6. **图像尺寸**：按同名在标注旁或配置的 `image_dir` 查找图像；优先复用 `convert.read_image_size`（不强制 OpenCV）。
7. **过滤**：跳过 `._*`、`.DS_Store`、缓存目录等非数据文件。

## 非功能性要求

1. 离线脚本，入口以模块内变量配置为主（IDE 直接运行）。
2. 单条坏文件跳过并告警，不中断整批。
