# 背景

封边标注同时存在真正缺陷与产线常见干扰物。客户 Label Studio 模板（`scanly/doc/00-客户资料/业务相关/标签分类.txt`）已把残带、钻孔、锯齿、标签标成「非缺陷」，但训练类别表 `TRAIN_CLASSES` 仍会收录这些框。若不区分角色，训练统计、推理启用和板级 NG 会把干扰物当成缺陷。

当前合并训练统计中，开胶（Tackless）与残带（ResidualTape）框数最多。残带等非缺陷必须能被模型认出，但不能作为对外缺陷报出。

# 目标

1. 明确列出核心缺陷类，作为检出、判定与验收的主目标。
2. 明确列出须屏蔽的非缺陷类，避免残带、钻孔、锯齿、标签进入 NG / 贴标 / 排出。
3. 对未划入上述两类的稀有类给出处理口径，避免与核心缺陷混用。

# 要求

## 功能性要求

1. **核心缺陷**（须检出并参与判定）：`Tackless`（开胶）、`GlueSeam`（胶缝）、`ClampGlue`（夹胶）、`GlueResidue`（残胶）、`GlueGap`（崩缺）、`Longer`（过长）、`Bumps`（鼓包）、`Scrape`（刮板）、`Shorter`（短带）、`BandBroken`（封边带损伤）、`Below`（封边过低）、`Longer2`（过长2）。
2. **屏蔽非缺陷**（标注可画框、训练可保留，推理默认屏蔽）：`ResidualTape`（残带）、`Hole`（钻孔）、`Zigzag`（锯齿）、`Label`（标签）。屏蔽指：`is_defect=false`，方案默认 `enable=false`，不出现在对外缺陷结果，不置 NG / 贴标 / 排出。
3. **训练保留**：屏蔽类允许进入 `TRAIN_CLASSES`，避免与残胶、开胶等核心类混淆。不得因「非缺陷」而从标注规范中删除。
4. **未划入两类的稀有类**：`BandBroken2`（**疑似**封边带损伤，样本极少）、`Above`（封边过高，方案默认关闭且不在默认 `TRAIN_CLASSES`）、`Scratch`（划伤，样本极少；表面伤以 `Scrape` 为准）。不作为核心缺陷验收项，也不按屏蔽非缺陷处理。`BandBroken` 为**确定缺陷**（通常可见破损面）；`BandBroken2` 为**疑似缺陷**（通常看不到清晰破损面）。角部缺料仍优先 `GlueGap`，不得用 `BandBroken2` 代替崩缺。
5. **对照表**：`GET /v1/labels` 中屏蔽类必须 `is_defect=false`；核心缺陷必须 `is_defect=true`。`ClampGlue` 虽方案可默认关闭，仍属核心缺陷。

## 非功能性要求

1. 类别角色以本文件为准；客户模板中的「非缺陷」文案与本文件屏蔽类一致。
2. 不得把 `Hole` 当成崩缺、把 `ResidualTape` 当成封边带损伤、把 `Zigzag` 当成须报出的波浪纹。
