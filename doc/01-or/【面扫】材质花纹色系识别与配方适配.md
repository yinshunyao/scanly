# 背景

封边缺陷检测现场板件饰面材质、花纹与色系差异大，同一缺陷在不同底板上的对比度与纹理干扰不同。仅靠人工选方案或 MES 标称颜色，易出现进板后实际花纹与模型/曝光不匹配，导致线扫漏检、误报。

物料清单已配置 **2 台面扫相机**（如 `MV-CS004-11GC`）与对应镜头，以及 **3 台线扫**负责封边上/中/下在线检缺。客户软件已有浅/深板 × 浅/深封边等色系工程方案、相机曝光增益与缺陷面积/长度阈值，但未将面扫识别贯通为自动配方与参数适配。

需用两台面扫在进板阶段完成材质/花纹/色系识别，映射到可配置的检测配方集，并同步调整曝光等成像参数与算法判定阈值，使后续线扫缺陷识别与 OK/NG 判定与当前板面状态匹配。**适配参数套数不固定为四套**：现场初版可兼容客户现有四分色方案，实际配方粒度与数量在算法迭代中按样本覆盖、可分性与实现成熟度确认。

# 目标

1. 利用物料清单中的两台面扫，在进板后稳定识别板件与封边相关的材质、花纹与色系特征。
2. 将识别结果自动映射到可配置的工程配方（初版兼容浅/深板 × 浅/深封边等既有方案；套数可扩展）。
3. 按方案自动适配线扫（及必要的面扫）曝光、增益等成像参数，保障不同色系/花纹下的可检性。
4. 按方案自动装载缺陷检测算法权重与物理判定阈值（宽/长/面积等），降低错配方导致的系统性误判。
5. 在 MES 先验与面扫实测冲突时提供可配置优先级与异常告警，避免静默错配。
6. 支持配方集合随算法迭代增删；不以「固定四套」为最终产品上限。

# 要求

## 功能性要求

1. **硬件范围**：面扫数量与型号以物料清单为准——2 套面扫（如 `MV-CS004-11GC` + 配套镜头）；不替代 3 路线扫的在线缺陷主检职责。
2. **识别输出**：对当前进板输出特征足以决议 `recipe_id`；初版至少含 `panel_tone`（如浅/深）、`edge_tone`（如浅/深）、可选 `pattern_id`（花纹/材质类）与置信度；后续可扩展特征维度（高/中/低反光、细花纹级等）。两台面扫覆盖「板面」与「对照面（另一饰面或封边带可见面）」语义。
3. **方案适配**：识别结果必须解析为 `recipe_id`，再绑定一套适配参数包（曝光、模型、阈值等）。
   - **基线兼容**：系统须能覆盖客户既有默认方案类型（浅板×浅边、浅板×深边、深板×深边、深板×浅边）及其模型槽位语义。
   - **套数不锁死**：配方/参数包总数 **不限定为 4**；可按材质、花纹粗类、反光等级等继续细分。具体分层、命名与数量在**算法迭代中按实现程度与样本可分性确认**后固化，并回写配置与验收范围。
   - 支持另存/导入自定义方案，并绑定面扫标签或 MES 关键字。
4. **成像参数适配**：`recipe_id` 生效时，边端须将该方案绑定的**线扫曝光、增益**（及现场已使用的相关光源/行频项）下发至三路线扫；面扫自身曝光可随方案微调以便识别稳定。
5. **算法阈值适配**：`recipe_id` 生效时，缺陷检测须加载方案绑定的 **AI 模型组（det+cls）** 与 **物理阈值表**（宽/长/面积过滤等），不得写死「全局唯一」阈值而忽略当前配方。多套模型可共享同一检测骨干而仅换阈值/曝光，亦允许按配方独立权重——以实现与检出效果择优，不在需求层锁死。
6. **与 MES/板件信息协作**：可读码/MES 中的纹理、颜色等先验；默认策略为 **面扫实测优先**，MES 仅作校验；若置信度低于阈值或与 MES 强制字段冲突，按配置执行「告警并停检 / 告警并用 MES / 告警仍用面扫」之一，且结果可追溯。
7. **时序**：面扫识别与配方下发须在本板**线扫缺陷热路径推理开始前**完成；不得在条带热路径内阻塞等面扫长时间重试。
8. **降级**：面扫掉线、识别失败时，可回退到 MES 映射方案或上一板同一批次方案（策略可配），并告警；不得静默使用未知配方继续检板而不留记录。

## 非功能性要求

1. **识别时延**：单次双面扫识别 + 方案切换（含相机参数下发）目标 ≤ 200 ms（不含机械等待），不得拖垮 60 m/min 节拍下的可排产性。
2. **稳定性**：同一批同配方连续板，误切换配方率应可控（现场验收可约定，目标误切 < 1%）。细分套数增加后，以**同一 `recipe_id` 连续段**统计，不因配方总数上升放宽错配方无告警。
3. **可扩展性**：增加/停用配方不得改 MES/PLC/视觉中心外发协议；仅配置与模型/阈值资产变化。
4. **边界**：面扫不做白皮书级毫米缺陷主检；厚度引起的相机高度调节仍走现有机构/PLC 路径，不由面扫替代。
5. **兼容**：不强制改造 MES/贴标/出料中控协议；视觉中心仍只接收板级缺陷结果。
