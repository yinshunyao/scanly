# 功能设计

## 入口与配置

`stat_annotation.py` 提供 `AnnotationStats` 与 `run_stats(...)`。`__main__` 用变量配置：

| 变量 | 含义 |
|:---|:---|
| `SAMPLE_DIR` | 样本/数据集根（写入报告头） |
| `ANNOTATION_DIR` | 标注目录（可覆盖；YOLO 常用 `labels/train`） |
| `IMAGE_DIR` | 图像目录（YOLO 常用 `images/train`） |
| `ANNOTATION_FORMAT` | `yolo` / `voc` |
| `CATEGORIES_PATH` | 可选类别表；缺省可读 `data.yaml` names |
| `RECURSIVE` | 是否递归搜标注 |
| `USE_DIAGONAL` | True=对角线，False=最长边 |
| `OUTPUT_PATH` | 统计报告路径 |

## 解析

### YOLO txt

每行 `class_id cx cy w h`（归一化）。像素宽高 = 归一化 × 图像宽高。

### VOC xml

读取 `size/width|height` 与各 `object` 的 `name`、`bndbox`，像素 `w=xmax-xmin`、`h=ymax-ymin`，再归一化。

## 统计输出（与 insect 对齐）

1. 文件级：标注文件数、空标注数、缺图数  
2. 类别映射（有名称时）  
3. 归一化尺寸指标：均值/最小/最大  
4. 像素尺寸指标 + 面积均值/最小/最大  
5. 每类极值对应标注文件  
6. 像素尺寸分箱表（`PIX_BOX_BIN_EDGES`）

# 约束与边界

- 不统计多边形/分割；仅矩形框。
- 不依赖 insect 工程与 OpenCV；图像尺寸走 `convert.read_image_size`。
- 不修改原始标注，只读统计。
