# 功能设计

## 输入识别

`convert_dataset(input_dir, ...)` 按下列顺序判定：

1. 根目录存在 `Categories.json` → 沿用原客户 JSON 转换（单层，行为不变）。
2. 否则递归发现 YOLO 包：目录同时含 `images/` 与 `labels/` 即为一包；进入某包后不再向下搜。
3. 两者皆无 → 报错。

`cam-all-0901` 走第 2 路：`cam1&3/Bumps`、`cam2/Below` 等均为独立包。

## 类别映射

各包 `classes.txt` 行序为本地 class id。不同包的表可以不一致（本套数据存在 13 / 15 / 19 类三种表）。

转换时：`本地 id → 本包名称 → 全局名称表`。全局表优先取各包 `notes.json` 中条目最多的 `categories`（按 id 升序），再并入各包 `classes.txt` 中尚未出现的名称。VOC XML 写名称；`predefined_classes.txt` 写全局表。

## 坐标

YOLO 行 `class_id cx cy w h`（归一化）→ 像素：

```
x1 = (cx - w/2) * W
y1 = (cy - h/2) * H
x2 = (cx + w/2) * W
y2 = (cy + h/2) * H
```

再走现有 `normalize_bbox` / `bbox_to_voc_ints` 裁剪。仅处理 5 列检测行，其它行告警跳过。

## VOC 扁平输出

```
output/voc/
├── JPEGImages/          # 全部图像，无子目录
├── Annotations/         # 全部 xml，无子目录
└── predefined_classes.txt
```

默认输出文件名 = 原图像 basename。`folder` 固定为 `JPEGImages`。

### 重名

| 情况 | 处理 |
|:---|:---|
| 同名且文件大小相同 | 视为重复样本，跳过后续份，计入 `duplicates` |
| 同名且大小不同 | 输出名改为 `{相对包路径}__{原文件名}`（`/` → `__`） |

## 入口

`convert.py` 的 `convert_dataset`；`__main__` 用变量指定 `INPUT_DIR`、`OUTPUT_FORMAT=voc`、`COPY_IMAGES`。

# 约束与边界

- 不把输入侧的 `cam/`、缺陷类型目录复制到 VOC。
- 不解析多边形 / OBB。
- 客户 JSON 单层转换行为保持不变。
- 不修改 `样本数据/` 原文。
