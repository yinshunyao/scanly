# 标注转换设计目录

## 目录用途

存放 scanly 缺陷样本标注格式转换相关的开发设计（Label Studio / 专用格式 → 训练与复核格式）。

## 文档范围

**允许放入：** 输入输出目录约定、坐标换算、类别映射、工具入口参数。

**不应放入：** 原始客户导出样例（放 `doc/00-客户资料/`）；测试用例表（放 `doc/03-tr/标注转换/`）。

## 编辑规则

- 命名：`编号.主题.md`
- 须含 `# 关联文档` 追溯到 OR
- 变更直接改对应章节

## 协作约定

| 相邻目录 | 关系 |
|:---|:---|
| `doc/01-or/` | 需求真源 |
| `doc/03-tr/标注转换/` | 同步测试设计 |
| `defects/tools/` | 转换脚本实现落点 |
