# 缺陷推理设计子目录

## 目录用途

存放家装封边缺陷推理服务的接口契约、判定逻辑与 Gradio/HTTP 服务设计，供边端客户端对接与算法实现对照。

## 文档范围

**允许放入：** HTTP 字段约定、类别/方案映射、单图推理与判定流程、Go 加密 ONNX 与 GPU 授权、与昆虫侧入口的对照说明。

**不应放入：** 客户截图原文（放 `doc/00-客户资料/`）；测试用例表（放 `doc/03-tr/缺陷推理/`）；启动命令细节（放 `doc/99-ops/`）。

## 编辑规则

- 命名：`编号.主题.md`（接口文档优先 `01.`）
- 须含 `# 关联文档`
- 客户端对接文档须自成一体（可不依赖读实现源码）
- 变更直接改对应章节；单文档建议不超过 300 行

## 协作约定

| `doc/01-or/` | 需求真源 |
