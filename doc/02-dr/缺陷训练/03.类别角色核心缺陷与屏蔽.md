# 功能设计

## 角色定义

| 角色 | 含义 | 训练 | 推理 |
|:---|:---|:---|:---|
| 核心缺陷 | 产线要检出的缺陷 | 进入 `TRAIN_CLASSES` | `is_defect=true`；参与 NG / 贴标 / 排出（方案可单独关某类） |
| 屏蔽非缺陷 | 常见干扰物，不是缺陷 | 允许进入 `TRAIN_CLASSES` | `is_defect=false`；默认 `enable=false`，框被丢弃 |
| 其它 | 未划入上两类 | 按样本与方案决定 | 不作为核心验收项 |

`TRAIN_CLASSES` 只决定「训练学哪些类」，不决定「对外算不算缺陷」。

## 屏蔽非缺陷

客户模板 Header 已写「非缺陷」。推理按干扰类屏蔽。

| name | 中文 | 框数 | 在 TRAIN_CLASSES |
|:---|:---|---:|:---|
| ResidualTape | 残带 | 1418 | 是 |
| Hole | 钻孔 | 35 | 是 |
| Zigzag | 锯齿 | 15 | 是 |
| Label | 标签 | 15 | 是 |

残带框数仅次于开胶。从训练中去掉会与残胶 / 开胶混淆，故训练保留、推理屏蔽。

屏蔽落地：`labels.py` / `labels.go` 中 `is_defect=false`；`scheme.json` 默认 `enable=false`。判定步骤 1 丢弃未启用类，结果中不出现。

## 旧映射纠正

早期 13 类表曾把干扰类当成缺陷。现以本表为准：

| 错误用法 | 正确用法 |
|:---|:---|
| `Hole` = 崩缺 | 崩缺是 `GlueGap`；`Hole` 是钻孔（屏蔽） |
| `ResidualTape` = 封边带损伤 | 封边带损伤是 `BandBroken`；`ResidualTape` 是残带（屏蔽） |
| `Zigzag` = 须报出的波浪纹 | `Zigzag` 是锯齿（屏蔽）；波浪纹 UI 类为 `BandWave`（当前无训练样本） |
