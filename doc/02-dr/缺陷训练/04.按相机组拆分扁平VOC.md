# 功能设计

## 入口

`scanly/train/tools/split_voc_by_camera.py`。`__main__` 变量：

| 配置项 | 含义 |
|:---|:---|
| `VOC_DIR` | 扁平 VOC，默认 `样本数据/cam-all-0901_voc` |
| `CAMERA_REF_DIR` | 相机对照根，默认 `样本数据/cam-all-0901`（含 `cam1&3`、`cam2`） |
| `OUTPUT_DIR` | 输出根，默认 `样本数据/came-split-0906-voc` |
| `DRY_RUN` | 仅统计不落盘 |
| `REPORT_PATH` | JSON 报告路径 |

## 分组算法

1. 扫描 `CAMERA_REF_DIR/cam1&3/**/images/*` 与 `CAMERA_REF_DIR/cam2/**/images/*`（亦兼容无 `images/` 时直接扫缺陷子目录下图片），收集 stem 集合 `S13`、`S2`。
2. 对 `VOC_DIR/JPEGImages`（及常见别名）中每张图：
   - stem ∈ `S13` 且 ∉ `S2` → 复制到 `OUTPUT_DIR/cam1&3/`
   - stem ∈ `S2` 且 ∉ `S13` → 复制到 `OUTPUT_DIR/cam2/`
   - 两边都有 → `conflict`，跳过
   - 都不在 → `unmatched`，跳过
3. 同 stem 的 `Annotations/*.xml` 一并复制；缺 xml 记 `missing_xml`。
4. 若源有 `predefined_classes.txt`，复制到两组输出根。

## 输出结构

```
came-split-0906-voc/
  cam1&3/
    JPEGImages/
    Annotations/
    predefined_classes.txt
  cam2/
    JPEGImages/
    Annotations/
    predefined_classes.txt
```

## 约束与边界

- 不修改 `VOC_DIR` 与 `CAMERA_REF_DIR`。
- 不按文件名末尾 `_a_b_c` 猜相机（该数字非相机号）。
- 目标已存在同名文件时覆盖写入（幂等重跑）。
