# 功能设计

## 入口

`scanly/train/test_core.py`。配置在 `__main__` 变量区。不对原始数据 prepare。

| 配置项 | 含义 |
|:---|:---|
| `OUTPUT_DIR` | 已预处理 YOLO 检测目录（与训练入口同一套 staging） |
| `MODEL_PATH` | `best.pth` / `last.pth` 或训练导出的 `best.onnx` |
| `MODEL_YML` | 与训练一致的 yaml（`.pth` 必填；`.onnx` 用于搭相同 val 预处理与 COCO evaluator） |
| `IMGSZ` / `BATCH` / `WORKERS` / `DEVICE` / `SINGLE_CLS` | 须与对应训练一致 |
| `SPLIT` | 默认 `test`，可改为 `val` |
| `TRAIN_PROJECT` / `RUN_NAME` | 指标输出目录；默认 `RUN_NAME` 带 `-test` |

相对 `MODEL_PATH` 相对 `scanly/train/`。复用 `test.py` 的 `resolve_model_path`、`assert_split_ready`。COCO 写出与评估用 YAML 覆盖项在 `test_core.py` 内实现，只引用训练入口已有符号（`DETECT_CORE_ROOT`、`read_class_names`、`solver_device`、`yolo_split_to_coco`），不要求现场同步更新 `train_core.py`。

## 流程

```
OUTPUT_DIR（images/{split} + labels + data.yaml）
        │  同步 data.yaml path；检查 split 非空
        │  YOLO txt → coco/annotations/instances_{split}.json
        ▼
MODEL_PATH 后缀
        ├─ .pth  → YAMLConfig + DetSolver.val()（val_dataloader 指向该 split）
        └─ .onnx → 同一 val dataloader 预处理，ONNX Runtime 推理，CocoEvaluator 汇总
        ▼
TRAIN_PROJECT/RUN_NAME/test_metrics.json
```

`.pth` 通过 `resume` 加载完整 solver state（含 ema，若 checkpoint 中有）。`.onnx` 输入为 `images` + `orig_target_sizes`，输出 `labels` / `boxes` / `scores`（与 `onnx_export.py` 一致）。`orig_target_sizes` 为原图宽高，框坐标与 COCO GT 同为原图像素。

不按分数阈值过滤 query，与训练 val 的 top-300 后处理对齐，避免 AP 被人为抬高或压低。

YOLO `.pt`：直接失败并提示使用 `scanly/train/test.py`。

## 指标

从 COCO bbox `stats` 取 AP（mAP50-95）、AP50、AP75、AR100；从 `eval['precision']` 按类汇总 AP50 与 AP50-95。`stats` / `catIds` 可能是 numpy 数组，须转成 Python 序列后再写 JSON，不得对数组做 `or []` 真值判断。`test_metrics.json` 字段：

- `backend`：`pth` 或 `onnx`
- `split`、`model`、`map50`、`map50_95`、`map75`、`ar100`
- `results`：COCO 12 项 stats
- `per_class_map50` / `per_class_map50_95`
- `save_dir`

独立入口默认文件名仍为 `test_metrics.json`。训练 `fit` 后自动评估写入同一训练 run 目录的 `val_metrics.json` / `test_metrics.json`（`run_val(..., metrics_filename=...)`）。

## 约束与边界

- 不写回 `样本数据/` 与 VOC 源。
- 不评估加密 `.onnx.enc`、不接入 Go 推理。
- `TEST_ONLY` 仍只做训练 run 的 val。`fit` 结束后由 `train_core.py` 自动 val，并在 `TEST_RATIO>0` 且 test 有图时自动 test；指标写在训练 run 目录。本入口负责事后补评（或显式 `SPLIT=val`）。
- 本版不画 PR 曲线图。
