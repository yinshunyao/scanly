# 功能设计

## 目录职责（对齐 insect）

| 目录 | 职责 |
|:---|:---|
| `scanly/train/train_detect_cfg/` | 公共数据：`data_cfg.json`、`load_cfg.py`（`merge_model_cfg`） |
| `scanly/train/train_detect_yolo/` | YOLO 检测训练超参：`train_config.json`；由 `train.py` 加载 |
| `scanly/train/train_detect_core/` | RT-DETRv2 训练超参：`train_config.json`；由 `train_rtdetrv2.py` 加载 |
| `scanly/train/train_detect_obb/` | OBB 训练超参：`train_config.json`；由 `train_obb.py` 加载 |

训练脚本仍留在 `scanly/train/` 根目录，避免搬动 `rtdetrv2_pytorch/` 相对路径；配置落在上述子目录。

## 公共 `data_cfg.json` 键

| 键 | 含义 |
|:---|:---|
| `source_data_root` | Label Studio YOLO 导出根；相对本目录解析 |
| `voc_xml_path` | 扁平 VOC 根；非空则优先于 `source_data_root`；空字符串/`null` 表示不用 |
| `train_classes` | 英文类名列表，顺序即 class id；空列表=全部可用类 |
| `voc_split.val_ratio` / `test_ratio` / `seed` | 划分 |
| `keep_empty_labels` | 过滤后无框是否保留负样本 |
| `copy_images` | `true` 复制图；`false` 软链 |

不含模型路径、epochs、batch、骨干 yaml 等训练项。

## 入口 `train_config.json` 键

**YOLO（`train_detect_yolo`）**：`output_dir`、`skip_prepare`、`prepare_only`、`train_project`、`model_path`、`device`、`single_cls`、`train`（`imgsz`/`epochs`/`batch`/`patience`/`workers` 等）。

**RT-DETRv2（`train_detect_core`）**：同上 staging 相关键，外加 `model_yml`、`tuning`、`tuning_url`、`run_prefix`、`close_mosaic`、`val_fitness_metric`、`export_onnx`、`lr`/`backbone_lr`/`weight_decay`；`train` 段承载超参。

**OBB（`train_detect_obb`）**：与 YOLO 类似，`model_path` 为 `*-obb.pt`；入口固定 `label_format=obb`。

入口可覆盖公共数据键（如 OBB 换批次时只改本入口 JSON 的 `source_data_root` / `train_classes`）。

## 合并与路径

`load_cfg.merge_model_cfg(model_cfg, model_cfg_dir=...)`：公共为底 → 入口非 `_` 键覆盖 → `train` 段逐键合并。返回 `(merged, data_cfg_dir)`。

相对路径：未覆盖的 `source_data_root` / `voc_xml_path` 相对 `train_detect_cfg/`；入口覆盖后相对 `model_cfg_dir`。`output_dir` / `train_project` / `model_yml` / `tuning` 相对入口配置目录。

## 入口 `__main__`

```text
CONFIG_PATH = <对应 train_config.json>
# RT-DETRv2 额外：TEST_ONLY / RESUME
main(config_path=CONFIG_PATH, ...)
```

`main` 内 `load_merged_cfg` → 解析源路径（`voc_xml_path` 非空则用之）→ 调用原有 `prepare_dataset` / `run_train`。

## 约束与边界

- 不改变 `prepare_dataset` 算法与 Ultralytics / RT-DETRv2 训练逻辑。
- 不把 insect / 其他工程目录加入 import。
- `test.py` / `test_rtdetrv2.py` 可从对应 `train_config` 读 `output_dir` 与 `train.imgsz`/`batch`，权重路径仍可在验证入口变量区指定。
