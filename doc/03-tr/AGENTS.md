# 测试设计目录（03-tr）

## 目录用途

存放 scanly 的测试需求与用例设计，建立「需求 → 设计 → 测试」追溯，指导后续自动化与现场验收（默认不强制先写自动化代码，除非交付明确要求）。

## 文档范围

**允许放入：**

- 与 `doc/02-dr/` 对应的测试设计、用例表、自动化标识

**不应放入：**

- 实现源码（`test/` 代码树后续按全局规则镜像）
- 运维发布说明

## 编辑规则

- 与开发设计同主题、同模块前缀命名
- 至少含：关联文档、测试范围、测试用例、自动化测试标识
- 修改 `02-dr` 设计时同步检查本目录对应文档

## 协作约定

| 相邻目录 | 关系 |
|:---|:---|
| `doc/01-or/` | 用例覆盖 OR 要求 |
| `doc/02-dr/` | 用例对齐设计接口与边界 |
| `doc/00-客户资料/` | 色系方案、缺陷阈值等验收口径引用 |
| `doc/02-dr/缺陷推理/` | HTTP 与判定设计；用例见 `03-tr/缺陷推理/` |
| `doc/02-dr/缺陷训练/` | 数据准备与训练；用例见 `03-tr/缺陷训练/` |

优先级：OR 要求的可验收性 > 设计契约 > 实现细节。
