# 缺陷推理测试设计目录

## 目录用途

存放缺陷推理 HTTP / Gradio 服务的测试范围与用例，建立需求 → 设计 → 测试追溯。

## 文档范围

**允许放入：** 接口字段校验、判定逻辑、启停/覆膜过滤、健康检查、Go License/GPU 授权等用例。

**不应放入：** 自动化源码（若后续交付，按 `scanly/test/` 镜像 `defects/predict`）。

## 编辑规则

- 至少含：关联文档、测试范围、测试用例、自动化测试标识
- 修改 `02-dr/缺陷推理` 时同步检查本目录
