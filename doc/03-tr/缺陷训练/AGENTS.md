# 缺陷训练测试设计目录

## 目录用途

存放封边缺陷训练（原始目录发现、类别过滤、格式转换、YOLO 与 RT-DETRv2 训练入口）的测试范围与用例。

## 文档范围

**允许放入：** 数据准备、训练配置、测试集验证、类别角色（核心缺陷 / 屏蔽非缺陷）、扁平 VOC 转 YOLO、RT-DETRv2 COCO 转换、ONNX 导出与加密相关用例。

**不应放入：** 自动化源码（若后续交付，按 `scanly/test/` 镜像 `scanly/train`）。

## 编辑规则

- 至少含：关联文档、测试范围、测试用例、自动化测试标识
- 修改 `02-dr/缺陷训练` 时同步检查本目录
