# 测试范围

- 公共 `data_cfg.json` 与入口 `train_config.json` 合并顺序与覆盖
- 相对路径解析基准（公共 vs 入口目录）
- `voc_xml_path` 优先于 `source_data_root`
- YOLO / RT-DETRv2 / OBB 入口默认读各自配置后行为与解耦前一致
- 改公共类别后两侧入口共用，无需改训练脚本
