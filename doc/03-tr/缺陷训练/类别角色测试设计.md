# 测试范围

- 核心缺陷与屏蔽非缺陷名单
- `/v1/labels` 的 `is_defect` / `in_train_set`
- 默认方案对屏蔽类的 `enable`
- 屏蔽类检出后不进入对外结果、不置 NG
- 旧映射不得把 Hole / ResidualTape / Zigzag 当核心缺陷

| 编号 | 前置条件 | 操作步骤 | 预期结果 | 自动化 |
