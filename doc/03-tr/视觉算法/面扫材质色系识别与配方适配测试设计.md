# 面扫材质色系识别与配方适配测试设计

## 1. 测试范围

| 范围 | 覆盖点 |
|:---|:---|
| 面扫识别 | 双相机路径读图；`panel_tone`/`edge_tone`/`pattern_id`/置信度 |
| 配方映射 | 配置表驱动的 N 套 recipe_id；含初版四分色兼容种子；扩展配方 |
| 冲突与降级 | MES 冲突、低置信、掉线、双源全无 |
| 曝光适配 | 切换 recipe 后线扫曝光/增益与方案表一致 |
| 阈值/模型 | InferRequest 携带 thresholds；模型组随 recipe 切换（可共用权重） |
| 扩展性 | 新增/停用配方无需改协议；未知 recipe 拒绝或降级 |
| 时序 | 首条线扫推理前 `recipe_ready`；超时降级 |
| 边界 | 面扫不产出缺陷主检结果；面扫掉线不拖死产线 |

不在本阶段强制范围：真实 60 m/min 满速产线压测（可作 A2/P2 现场项）；跨机视觉中心协议改动；最终 N 的数值（由算法迭代确认后补测）。

## 3. 自动化测试标识

| 层级 | 框架建议 | 目录（实现时） | 覆盖用例 |
|:---|:---|:---|:---|
| 单元 | pytest | `scanly/test/test_...`（镜像实现目录） | 映射表/Resolver；TC-A01–A04、A14–A16 |
| 接口 | pytest + 本地 HTTP/gRPC | 同上 | AreaInfer mock 图；InferRequest 字段 |
| 集成 | pytest + mock 相机 SDK | 同上 | TC-A10 曝光写参 |
| 现场/系统 | 清单走查 + 统计表 | 不设自动 | TC-F01–F03（覆盖**当时启用**的 N 套） |

**默认**：本文档先交付用例设计；**自动化代码仅在用户明确要求时**优先实现映射表与 Resolver。**N 变更后**回归扩展规则用例，不重写协议。

## 4. 验收要点（对齐 OR）

1. 双面扫能驱动**当前启用的配方全集**自动选择（含初版兼容种子及后续扩展）。  
2. 切换后曝光与阈值/模型与**该 recipe 参数包**一致。  
3. 冲突与掉线可追溯、无静默错配；未知 recipe 不静默。  
4. 套数扩展不破坏三路线扫缺陷主流程与现有中心/PLC 协议。  
5. 最终 N 在算法迭代确认后，以配置资产与本表 F 类现场用例更新验收范围。
