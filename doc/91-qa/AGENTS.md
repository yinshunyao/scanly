# 质量保障目录（91-qa）

## 目录用途

存放 scanly 缺陷推理相关问题分析与修复记录，建立问题到需求/设计的追溯。

## 文档范围

**允许放入：** Bug/现象描述、根因、涉及文件、设计约束更新。

**不应放入：** 原始需求正文（`01-or`）、接口契约正文（`02-dr`）。

## 编辑规则

- 命名：`【主题分类】问题简述.md`
- 至少含：问题描述、关联文档、根因分析、涉及文件

## 协作约定

| 相邻目录 | 关系 |
|:---|:---|
| `doc/01-or/` | 问题可追溯到需求 |
| `doc/02-dr/缺陷推理/` | 问题可追溯到设计 |
| `doc/03-tr/缺陷推理/` | 补充回归用例 |
| `defects/predict/` | 修复落点 |
