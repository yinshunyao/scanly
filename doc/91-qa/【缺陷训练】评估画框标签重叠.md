# 问题描述

test 画框图上，贴在一起的框（例如同一条缝上的橙色 FN 与红色 FP）标签锚在同一个左上角。后画的色块盖住先画的文字，类名读不全。

# 根因分析

`draw_eval_image` 把每条标签都放在框的 `(x1, y1-2)`，不看已经画过的标签。框线也和文字交替绘制，后画的框会压到先写的字上。

# 涉及文件

- `scanly/train/test_core_vis.py`：先画完全部框，再按占用矩形放置标签。相交时下移，图底放不下再右移。检测 mark 的 test 画框调用同一函数。

# 设计约束更新

标签矩形不得互相覆盖。优先保持在原框左上角附近并向下错开。
